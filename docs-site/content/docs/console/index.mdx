The console is a **Next.js 16** app (App Router, TypeScript, Chakra UI v3,
Drizzle + Postgres). It's single-user and password-protected. It subscribes to
MQTT, persists sessions and climate readings, and relays live data to the browser
over Server-Sent Events.

## Architecture

```text
ESP32 bar node   ──MQTT──▶  Mosquitto  ──sub──▶  Next.js server  ──SSE──▶  Browser
 VL53L0X (reps)             (broker)             (persists +               (live UI)
 DHT11 (climate)                                  relays)  ──▶  Postgres
 buzzer + IR                ◀──────────  config / IR / OTA  ◀──────────────
```

The server subscribes to MQTT, persists finished sessions and climate readings to
Postgres, and relays live data to the browser over Server-Sent Events. Control
flows back down over MQTT.

## Repository layout

```text
web/                 Next.js 16 app (App Router, TS, Chakra UI v3, Drizzle)
  src/app/           pages + API routes
  src/lib/           detection, mqtt, live bus, auth, streaks, env series
  src/db/            schema, queries, persistence, migration runner
  scripts/           mock-device.ts (no-hardware simulator), seed-env.mjs
firmware/helm/       ESP32 Arduino sketch + config template + wiring guide
mosquitto/           broker config
docker-compose.yml   web + Postgres + Mosquitto
```
